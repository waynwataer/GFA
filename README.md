# GFA Haverhill Dashboard · 자비스(Jarvis) v6.2

## 이번 업그레이드
1. **주거인구 옆 행정구역명 상시 표시**: `population.js`가 이제 주(State) 약어(`_state_abbr`)와 표시 중인 인구 합계(`_sum_population`)도 함께 반환합니다. 레이어 패널의 "주거인구" 아래에 "행정구역: Essex County, MA · 인구 xxx명" 줄이 항상 보이고, 지도를 옮길 때마다(패닝 자동 갱신, 주 경계 클릭 이동 모두) 함께 갱신됩니다.
2. **매물 선택 시 최근접 학교 2-3곳 하이라이트**: 매물을 클릭/선택하면 가장 가까운 학교 3곳의 지도 마커가 커지고 잠깐 바운스되며, 학군 섹션의 해당 학교 카드에도 금색 테두리와 "선택 매물에서 0.8km" 배지가 붙습니다.
3. **유사사례 비교(State/City 선택)**: 학군 섹션 하단에 비교 패널을 추가했습니다. State+City를 고르면 그 지역의 실제 U.S. Census 인구 데이터를 Haverhill과 나란히 비교해서 보여주고, "자비스에게 학교·범죄율 비교 요청" 버튼으로 AI 패널을 열어 심화 비교를 요청할 수 있습니다(특정 도시의 개별 학교·범죄 수치는 공개 API가 없어 자비스의 조사에 위임하며, 불확실하면 "확인 필요"라고 답하도록 프롬프트에 명시했습니다).
